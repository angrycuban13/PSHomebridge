# PSHomebridge Module

## Description

PSHomebridge is a PowerShell client module for Homebridge.

## PSHomebridge

### [Find-HomebridgePlugin](commands/Find-HomebridgePlugin.md)

Finds Homebridge plugins in the package registry.

### [Get-HomebridgeAccessory](commands/Get-HomebridgeAccessory.md)

Gets Homebridge accessories.

### [Get-HomebridgeAccessoryLayout](commands/Get-HomebridgeAccessoryLayout.md)

Gets the Homebridge accessory layout.

### [Get-HomebridgeBackup](commands/Get-HomebridgeBackup.md)

Gets scheduled Homebridge backups.

### [Get-HomebridgePlugin](commands/Get-HomebridgePlugin.md)

Gets installed Homebridge plugins.

### [Get-HomebridgePluginInformation](commands/Get-HomebridgePluginInformation.md)

Gets metadata for a Homebridge plugin.

### [Get-HomebridgeServerDiagnostic](commands/Get-HomebridgeServerDiagnostic.md)

Gets Homebridge server diagnostic information.

### [Get-HomebridgeStatus](commands/Get-HomebridgeStatus.md)

Gets Homebridge status information.

### [Get-PSHomebridgeConnection](commands/Get-PSHomebridgeConnection.md)

Gets saved PSHomebridge connections without exposing passwords.

### [Invoke-HomebridgeApiRequest](commands/Invoke-HomebridgeApiRequest.md)

Sends an authenticated request to the Homebridge API.

### [New-HomebridgeBackup](commands/New-HomebridgeBackup.md)

Creates a Homebridge backup.

### [Remove-HomebridgeBackup](commands/Remove-HomebridgeBackup.md)

Removes a scheduled Homebridge backup.

### [Remove-PSHomebridgeConnection](commands/Remove-PSHomebridgeConnection.md)

Removes a saved Homebridge connection.

### [Save-HomebridgeBackup](commands/Save-HomebridgeBackup.md)

Downloads a scheduled Homebridge backup.

### [Set-PSHomebridgeConnection](commands/Set-PSHomebridgeConnection.md)

Creates or updates a saved PSHomebridge connection.
