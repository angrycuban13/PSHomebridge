# PSHomebridge

PSHomebridge is a PowerShell 7 client module for the Homebridge UI API.

It provides typed commands for saved connections, status, accessories, plugins, diagnostics, and backups.

## Install

```powershell
Install-Module -Name PSHomebridge -Repository PSGallery
```
